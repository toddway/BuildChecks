BuildChecks Maven repository

This branch (gh-pages) is a static Maven repository serving the BuildChecks CLI. Resolve it from Gradle:

repositories { maven { url = uri("https://toddway.github.io/BuildChecks") } }
dependencies { buildchecks("com.toddway:buildchecks:4.0.0") }

Artifacts are published automatically on each tagged release. See the README for full integration recipes, including Homebrew and the install script for non-JVM projects.
